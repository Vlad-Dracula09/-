# Quote Parser

Простая программа на Python для парсинга цитат с сайта [Quotes to Scrape](https://quotes.toscrape.com/).

## Описание

Скрипт выполняет парсинг всех страниц сайта `quotes.toscrape.com`, извлекает цитаты, имена авторов и теги, а затем сохраняет полученные данные в JSON-файл.

## Функциональность

- **Автоматический парсинг** — обходит все страницы сайта до последней
- **Извлечение данных** — собирает текст цитаты, имя автора и список тегов
- **Сохранение в JSON** — структурированное хранение данных с поддержкой кириллицы
- **Индикация прогресса** — отображает номер обрабатываемой страницы

## Используемые технологии

- `requests` — для отправки HTTP-запросов
- `BeautifulSoup4` — для парсинга HTML-разметки
- `json` — для сохранения данных в JSON-формате

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Vlad-Dracula09/-.git
cd quote-parser
```

2. Установите зависимости:
```bash
pip install requests beautifulsoup4
```

## Использование

Запустите скрипт:
```bash
python i.py
```

После выполнения в папке со скриптом появится файл `quotes.json` со всеми собранными цитатами.

### Пример выходных данных

```json
[
  {
    "text": "“The world as we have created it is a process of our thinking. It cannot be changed without changing our thinking.”",
    "author": "Albert Einstein",
    "tags": ["change", "deep-thoughts", "thinking", "world"]
  },
  ...
]
```

## Структура кода

- `parse_quotes()` — основная функция парсинга, возвращает список цитат
- `save_to_json()` — сохраняет данные в JSON-файл
- Автоматический запуск парсинга и сохранения при выполнении скрипта

## Примечания

- Скрипт завершает работу, когда достигает страницы с кодом ответа 404 или пустой страницы
- Все данные сохраняются с корректной кодировкой UTF-8
- Для образовательных целей — сайт специально создан для тренировки парсинга
